# Paradise Nursery - E-Commerce Plant Shopping Application

## Project Overview
Paradise Nursery is a React-based e-commerce web application designed for plant enthusiasts to browse, select, and purchase various houseplants. The application features a landing page, an interactive product catalog categorized by plant types, and a fully functional dynamic shopping cart built using React and Redux Toolkit.

## Key Features
- **Landing Page:** Features a background image, company overview, and a "Get Started" button to enter the shop.
- **Product Catalog:** Displays houseplants organized into multiple categories (e.g., Air Purifying, Aromatic, Medicinal) with details including thumbnail, name, description, and price.
- **Interactive Shopping Cart:** 
  - Dynamic cart counter in the navigation bar.
  - Ability to add items, increment/decrement quantities, or remove items.
  - Automatically calculates individual item totals and overall cart total.
  - "Continue Shopping" and "Checkout" actions.

## Tech Stack
- **Frontend Framework:** React.js
- **State Management:** Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling:** CSS3
